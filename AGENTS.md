# DAF - Dusk Audio Framework

The working rules for this repository live in **[CLAUDE.md](CLAUDE.md)**, which is the single
copy of them:

- the hard-fork policy — nothing is merged from DISTRHO/DPF, nothing is submitted to it, and the
  `upstream` remote stays removed rather than kept as a tempting safety net
- commit messages, including the ban on AI attribution trailers and the three layers that enforce it
- how pull requests are targeted, and why they are same-repo only
- what the three CI workflows cover

Read that file before changing anything here.

This one exists so that an agent looking for `AGENTS.md` is pointed at the rules rather than
finding nothing. It deliberately does not restate them: the copy this file replaced was a
mechanical find-and-replace of CLAUDE.md that had already drifted into naming paths that do not
exist, which is exactly what a second copy does over time.
